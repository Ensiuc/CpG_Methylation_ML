Analysis Pipeline

1

Data Loading & QC

Load CpG beta matrices per dataset. Coverage filtering, variance filtering, align CpG positions across datasets.

pandas numpy scipy
2

Unsupervised Exploration

PCA, UMAP, and hierarchical clustering heatmap. Color by condition, dataset, tissue. Identify natural sample groupings.

scikit-learn PCA umap-learn seaborn clustermap
3

Supervised Classification

ElasticNet with LOOCV for small datasets. ElasticNet + Random Forest with 5-fold CV for preconception stress. Feature importance = key CpGs.

ElasticNet Random Forest LOOCV / 5-fold CV
4

Multi-Dataset Integration (MOFA+)

Latent factor decomposition across all four datasets simultaneously. Identifies shared vs. exposure-specific methylation factors.

mofapy2 Multi-group MOFA
5

Cross-Dataset Validation

Per-CpG meta-analysis combining effect sizes across datasets. Fixed-effects model. Identifies CpGs consistently important across all exposures.

statsmodels scipy Meta-analysis

Dimensionality Reduction & Unsupervised
PCA — Principal Component Analysis
Linear dimensionality reduction · scikit-learn
✓ Selected ▼

Finds the directions of maximum variance in the CpG beta matrix. Each principal component is a linear combination of CpG positions. Used to visualize sample separation and identify which CpGs drive the most variance.

Pros

  • Fully interpretable — loadings map to CpGs
  • Deterministic — same result every run
  • Works with any sample size
  • No hyperparameters to tune
  • Quantifiable variance explained
  • Gold standard in omics

Cons

  • Linear only — misses non-linear patterns
  • Sensitive to outliers
  • May reflect batch effects
  • First PCs may not reflect biology
scikit-learn docs ↗ StatQuest tutorial ↗
Why selected: Essential first step — linear, interpretable, works with all sample sizes including small N datasets. CpG loadings directly tell us which positions drive variation.
UMAP — Uniform Manifold Approximation
Non-linear dimensionality reduction · umap-learn
✓ Selected ▼

Non-linear dimensionality reduction that preserves both local and global structure. Captures complex methylation patterns that PCA's linearity would miss. Used as a follow-up to PCA.

Pros

  • Captures non-linear structure
  • Preserves global structure better than t-SNE
  • Faster than t-SNE
  • Visually intuitive clusters
  • Handles high-dimensional data

Cons

  • Not deterministic by default
  • Sensitive to n_neighbors, min_dist
  • No direct feature loadings
  • Unreliable with very small N (<20)
  • Cluster distances not meaningful
UMAP docs ↗ Interactive explainer ↗ Original paper ↗
Why selected: Complementary to PCA — captures non-linear patterns. Used cautiously for small datasets (obesity, cfDNA). Primary use on wildfire (n=22) and stress (n=70) cohorts.
t-SNE — t-Distributed Stochastic Neighbor Embedding
Non-linear dimensionality reduction · scikit-learn
✗ Excluded ▼

Non-linear method focused on local neighborhood preservation. Widely used historically but largely superseded by UMAP for most applications.

Pros

  • Excellent local cluster separation
  • Widely cited in literature

Cons

  • Does not preserve global structure
  • Distances between clusters meaningless
  • Very slow on large datasets
  • Cannot embed new data points
  • Superseded by UMAP
How to use t-SNE effectively ↗
Why excluded: UMAP is strictly better — faster, preserves global structure, can embed new points. No reason to use t-SNE when UMAP is available.
Hierarchical Clustering Heatmap
Unsupervised clustering · seaborn / scipy
✓ Selected ▼

Builds a dendrogram of samples and CpG positions based on methylation similarity. Visualized as a heatmap (samples × CpGs) revealing spatial methylation patterns within the region.

Pros

  • Shows actual beta values — highly interpretable
  • Reveals spatial sub-regions within locus
  • Works with any sample size
  • No cluster number needed in advance
  • Standard in epigenomics publications

Cons

  • Sensitive to distance metric choice
  • Clusters not statistically validated
  • Color scale affects visual perception
seaborn clustermap ↗ scipy hierarchical ↗
Why selected: The most direct way to visualize methylation patterns across the ~7–8kb region. Can reveal whether a specific sub-region (e.g., part of the CpG island) drives differences.
Supervised Classification
ElasticNet Logistic Regression
Regularized classification · scikit-learn
✓ Selected — Primary ▼

Logistic regression with combined L1 + L2 regularization. L1 drives some CpG coefficients to zero (feature selection); L2 handles correlated CpGs by distributing weight across them rather than arbitrarily zeroing all but one.

Pros

  • Handles correlated features (critical for CpGs)
  • Automatic feature selection via L1
  • Works well with small N
  • Coefficients are directly interpretable
  • Fast training and cross-validation
  • Validated in methylation literature

Cons

  • Assumes linear relationship
  • Requires hyperparameter tuning (alpha, l1_ratio)
  • Unreliable at very small N (<10)
scikit-learn docs ↗ Zou & Hastie 2005 ↗
Why selected as primary: CpGs within a region are spatially correlated. LASSO would arbitrarily drop correlated CpGs; ElasticNet's L2 component distributes weight across them, preserving spatial information. LOOCV used for small datasets; 5-fold CV for stress cohort.
Random Forest
Ensemble classification · scikit-learn
~ Selected (stress only) ▼

Ensemble of decision trees trained on bootstrap samples and random CpG subsets. Feature importance from mean decrease in impurity reveals which CpGs best discriminate conditions across trees.

Pros

  • Captures non-linear patterns
  • No feature scaling needed
  • Built-in OOB error estimate
  • Robust to outliers
  • Works with correlated features

Cons

  • Needs N > 20 per class minimum
  • Less interpretable than ElasticNet
  • Feature importance can be biased
  • Many hyperparameters
scikit-learn docs ↗ Breiman 2001 ↗
Why selected (stress only): Only the preconception stress cohort (n≈70) has sufficient sample size for Random Forest. Used alongside ElasticNet to compare feature importance — agreement between models strengthens CpG candidates.
Support Vector Machine (SVM)
Kernel-based classification · scikit-learn
✗ Excluded ▼

Finds a maximum-margin hyperplane separating classes. With RBF kernel, captures non-linear boundaries. Effective in high-dimensional spaces.

Pros

  • Works in high-dimensional spaces
  • Effective when classes are separable
  • Kernel trick allows non-linearity

Cons

  • No native feature importance
  • Slow to tune (C, kernel, gamma)
  • Not interpretable
  • No probability output by default
  • Unreliable with small N
scikit-learn SVM ↗
Why excluded: Interpretability is a priority — we need to know which CpGs matter. SVM requires post-hoc methods (SHAP) to extract feature importance, adding complexity without clear benefit over ElasticNet.
Neural Networks / Deep Learning
PyTorch / TensorFlow
✗ Excluded ▼

Multi-layer non-linear models. CNNs have been applied to methylation array data for disease classification at scale.

Pros

  • Learns complex patterns automatically
  • CNNs can model CpG spatial relationships
  • State of the art for large datasets

Cons

  • Requires N > 100 per class minimum
  • Completely uninterpretable
  • Guaranteed to overfit here
  • Cannot be validated with our sample sizes
  • Computationally expensive
PyTorch ↗
Why excluded: Total samples across all datasets ≈ 120. Deep learning requires hundreds to thousands of samples per class. Applying neural networks here would produce severely overfit, uninterpretable, and unvalidatable models.
Multi-Dataset Integration
MOFA+ — Multi-Omics Factor Analysis
Probabilistic latent factor model · mofapy2
✓ Selected — Primary Integration ▼

Probabilistic framework that decomposes data from multiple groups into shared and group-specific latent factors. Each factor has loadings on CpG positions, identifying which sites drive shared vs. dataset-specific variation.

Pros

  • Designed exactly for this use case
  • Handles unequal sample sizes naturally
  • No batch correction needed
  • Separates shared from specific signals
  • CpG loadings are interpretable
  • Handles missing CpGs per dataset
  • Python API available (mofapy2)

Cons

  • Number of factors K must be chosen
  • Convergence requires multiple runs
  • Python API less documented than R
  • More complex than simple PCA
Argelaguet et al. 2020 ↗ mofapy2 GitHub ↗ Tutorials ↗
Why selected: MOFA+ is the only tool that explicitly models multiple biological groups with the same features. It answers our core question — which CpGs show consistent patterns across obesity, wildfire, and stress — without requiring batch correction or equal sample sizes.
Harmony
Batch correction · harmonypy
✗ Excluded ▼

Iterative batch correction that adjusts PCA embeddings to remove technical batch effects while preserving biological variation. Originally developed for single-cell RNA-seq.

Pros

  • Very effective at batch correction
  • Fast — works on PCA embeddings
  • Widely used in single-cell omics

Cons

  • Correction tool, not integration tool
  • Can remove real biological signal
  • Tissue and dataset are confounded here
  • Does not identify shared factors
Korsunsky et al. 2019 ↗ harmonypy ↗
Why excluded: Harmony removes variation between datasets — but in this project, the between-dataset biological signal is exactly what we want to study. MOFA+ models it; Harmony would erase it.
Per-CpG Meta-Analysis
Statistical integration · statsmodels / scipy
✓ Selected — Validation ▼

Combines effect sizes (Cohen's d or regression coefficients) per CpG from separate analyses of each dataset using fixed-effects or random-effects models. Statistically validates MOFA+ findings.

Pros

  • Statistically rigorous and well-validated
  • Handles different sample sizes (weights by precision)
  • No raw data alignment required
  • Already used in prior analysis (metafor)
  • Per-CpG resolution

Cons

  • Operates on summary statistics — less power than joint modeling
  • Fixed-effects assumption may not hold across tissues
  • Does not identify latent shared factors
statsmodels ↗ metafor (R) ↗
Why selected: Builds directly on the previous analysis (metafor in R). Used as a validation layer — CpGs identified by MOFA+ as shared should also show consistent effect sizes across datasets in the meta-analysis.
